## Entry

One joke about office life, one line, under 200 characters, written by
`main.py` (Python 3 stdlib only) to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> I had to book a meeting to grieve the free time I lost booking meetings — it got rescheduled twice.

The joke turns the calendar on itself: the meeting meant to mourn lost
free time gets rescheduled, so the punchline is the same disease it
complains about. No stock "this meeting could have been an email" line,
no pun — a true observation with a surprising last word, tight enough
to read aloud in one breath.

## Run

```sh
python3 main.py
```

Writes `entry.txt` (one line, 96 characters) to `$MAKEFUN_OUTPUT_DIR`
(default `/output`).
